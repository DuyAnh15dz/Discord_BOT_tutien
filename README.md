# 🧘 Discord Bot Tu Tiên

Bot Discord tu tiên với hệ thống tu luyện, cảnh giới, linh căn, luyện đan...

> ⚠️ **Trạng thái:** Đang phát triển (Beta) - Chưa test đầy đủ, chưa public

## ✨ Tính năng

- 🧘 **Tu luyện** - Tăng cảnh giới theo thời gian
- 🌟 **Linh căn** - Roll linh căn ngẫu nhiên khi bắt đầu
- 💊 **Luyện đan** - Chế tạo đan dược từ dược liệu
- ⚔️ **Đột phá** - Vượt cảnh giới với tỉ lệ thành công
- 📅 **Lịch luyện** - Sự kiện tu luyện theo thời gian
- 🏆 **Bảng xếp hạng** - So tài tu vi giữa các đạo hữu
- 🛒 **Shop** - Mua bán vật phẩm, công pháp
- 📿 **Công pháp** - Trang bị công pháp tăng thuộc tính
- 🎒 **Túi đồ** - Quản lý inventory
- 🌿 **Dược liệu** - Thu thập và chế biến

## 🚀 Cài đặt

```bash
# Clone repo
git clone https://github.com/DuyAnh15dz/Discord_BOT_tu_tien.git
cd Discord_BOT_tu_tien

# Tạo virtual environment
python -m venv .venv

# Activate (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# Cài dependencies
pip install -r requirements.txt
